# Operations

How we run BuildFlow day-to-day.

- **RUNBOOKS.md** — Standard procedures (coming soon)
- **PROCESSES/** — Checklists for common tasks

  - INCIDENT_RESPONSE.md — What to do if things break (coming soon)
- **logs/** — Daily standup notes + monthly summaries
  - 2026-09-11.md (example)

## Weekly Routine

**Every Friday:**
- Update `../PROGRESS.md` with this week's wins/blockers/next week's focus
- Review `METRICS.md` (do we hit targets?)
- Add entry to `logs/2026-09.md` if there's something notable

**Every Month (1st of month):**
- Summarize financial metrics (revenue, closes, costs)
- Update `logs/2026-09.md` (month-end snapshot)
- Email stakeholders with monthly report
