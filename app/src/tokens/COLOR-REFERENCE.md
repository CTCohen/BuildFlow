## Notes for Developers

1. **Semantic naming** - Use token names (primary, accent, success) not hex values in code
2. **Dark mode** - Always include both `light_mode` and `dark_mode` tokens
3. **Contrast** - All variants AAA-compliant; verify custom combinations
4. **Accessibility** - Use semantic colors for status indicators
5. **Maintenance** - Update variants in one place (here), propagates to all components
