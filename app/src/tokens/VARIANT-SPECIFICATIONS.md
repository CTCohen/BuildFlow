# Variant Specifications

Complete specifications for all 5 color scheme variants in the Fornax token system.

---

## 1. Emergency Red + Orange

**File:** `emergency-red-orange.ts`

**Positioning:** Urgency, immediate action, 24/7 response

**Target Industries:**
- HVAC emergency services
- Emergency plumbing repairs
- Same-day service businesses
- Fast-response positioning

**Design Psychology:**
- Red conveys urgency and immediate action
- Orange suggests energy and approachability
- Combination: "We respond fast to your crisis"

**Light Mode Colors:**
```
Primary Base:        #dc2626 (Red-600)
Accent Base:         #ea580c (Orange-600)
Text Primary:        #1f2937 (Gray-800)
Neutral Surface:     #ffffff (White)
```

**Dark Mode Colors:**
```
Primary Base:        #ef4444 (Red-500)
Accent Base:         #f97316 (Orange-500)
Text Primary:        #f3f4f6 (Gray-100)
Neutral Surface:     #111827 (Darkest)
```

**WCAG Ratio:** 7.4 (AAA compliant)

**Use Case Examples:**
- "24/7 Emergency Service" hero banner
- "Call Now" emergency CTA buttons
- "Same Day Response" badges
- Real-time availability indicators
- Urgent appointment reminders

**Component Variations:**
- Primary button: Red on white → glowing effect
- Urgent badge: Red background, white text
- Alert banner: Full-width red header with orange accent stripe
- Emergency contact card: Red border on left, large orange phone icon

## Design Flexibility

### Emergency Red + Orange
**Can be used for:** Urgent services, emergency response, fast track options
**Should avoid:** Calming/meditative services, luxury positioning

### Premium Deep + Refined
**Can be used for:** Upscale services, expert positioning, membership tiers
**Should avoid:** Budget positioning, urgent/emergency services

### Trust Blue + Warm
**Can be used for:** Established trades, balanced positioning, community focus
**Should avoid:** Extreme urgency (use Emergency instead), luxury (use Premium instead)

### Visual Vibrant Green + Gold
**Can be used for:** Visual trades, before/after portfolios, nature-focused
**Should avoid:** Non-visual services, luxury (use Premium instead)

### Standard Professional Blue + Warm
**Can be used for:** Broad market appeal, mainstream positioning, industry standard
**Should avoid:** Ultra-premium (use Premium), ultra-urgent (use Emergency)

## Implementation Notes

### 1. Color Consistency
All variants maintain semantic color consistency. Primary text color is always dark (#1f2937) or light (#f3f4f6) depending on mode.

### 2. Dark Mode
Each variant has a complete dark mode color set. Colors are brightened appropriately for dark backgrounds.

### 3. Accessibility
- All variants meet WCAG AAA standards (7:1 minimum)
- Text always has sufficient contrast regardless of background
- Semantic colors are tested against both light and dark backgrounds

### 4. Component Reusability
The same components work with any variant by using token names instead of hardcoded colors.

### 5. Neutral Colors
Neutral grays are shared across all variants for backgrounds, borders, and dividers.

## Selection Checklist

When choosing a variant, consider:

- [ ] What is the primary service category? (emergency, premium, traditional, visual, mainstream)
- [ ] What is the target market perception? (urgent, exclusive, trustworthy, skilled, standard)
- [ ] Does the business emphasize speed or quality? (urgency or premium positioning)
- [ ] Is there visual component to the work? (portfolio/before-after important?)
- [ ] What's the primary audience? (premium buyers, value-conscious, mainstream)
- [ ] Do brand standards require specific colors? (Match or use closest variant)

---

## Performance Notes

All token files are lightweight TypeScript modules that:
- Import once at app startup
- Use CSS variables for runtime efficiency
- Support static optimization in Astro
- Produce minimal bundle size impact

No runtime color calculations needed; all colors are pre-computed and stored as hex values.
