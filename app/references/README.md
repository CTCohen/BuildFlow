# references/

The visual bar. Drop 8–12 screenshots of local service-business sites that represent the
quality level every BuildFlow site must hit (and a few "what not to do" for contrast).

## How to use

- When generating or critiquing a site, these images are given to Claude as the target:
  "match this level of hierarchy, spacing, typographic polish, credibility."
- Name files `NN-trade-note.png`, e.g. `03-roofing-strong-hero.png`, `09-hvac-too-generic.png`.
- Keep a one-line note per file below.
