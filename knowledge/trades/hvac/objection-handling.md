# HVAC buyer objections → what the page must answer

| Objection | Where it's answered | How |
|---|---|---|
| "Can they come today?" | hero + every service page opener | explicit same-day / emergency window |
| "Are they legit / licensed?" | hero trust strip, about, footer | ROC licence #, "bonded & insured", years |
| "Will they overcharge / surprise me?" | service pages, offer block | "quote before we start", diagnostic fee stated, "no trip charge with repair", free estimates |
| "Can I afford a $8–15k replacement?" | AC/heat install pages, offer block | financing offer + monthly figure, tax-credit & rebate mention |
| "Do they know my system?" | about, service pages | brands serviced, NATE/EPA, factory-authorized dealer |
| "Are they actually local?" | area pages, service-area block | named suburbs, drive time, local reviews |
| "Are they any good?" | reviews block sitewide | embedded Google reviews + quotes with name + suburb |
| "What if it goes wrong?" | service pages, about | workmanship warranty length, parts warranty |

Rule: if a page asks for a call, every objection above must be answerable from what's
visible on that page or one click away.

## Check
- Reviewer walkthrough: on the home page and any one service page, all 8 objections have
  a visible or one-click answer.
- LLM rubric "completeness" ≥ 4/5.
