# HVAC keyword → page map

Each page targets one primary intent. `<city>` = the page's city; `<metro>` = primary metro.

| Page | Primary | Secondary / long-tail |
|---|---|---|
| `/` | `hvac <metro>`, `ac repair <metro>` | `heating and cooling <metro>`, `<brand> dealer <metro>` |
| `/services/ac-repair` | `ac repair <city>` | `ac not cooling`, `ac blowing warm air <city>`, `emergency ac repair <city>` |
| `/services/ac-installation` | `ac installation <city>` | `ac replacement cost <city>`, `new ac unit <city>`, `hvac financing <city>` |
| `/services/heating-repair` | `heating repair <city>` | `furnace not working <city>`, `no heat <city>`, `furnace won't ignite` |
| `/services/heating-installation` | `furnace installation <city>` | `heat pump installation <city>`, `furnace replacement cost` |
| `/services/maintenance` | `ac tune up <city>` | `hvac maintenance plan <city>`, `furnace tune up <city>` |
| `/services/emergency-hvac` | `emergency hvac <city>` | `24 hour ac repair <city>`, `same day ac repair <city>` |
| `/areas/<city>` | `hvac <city>`, `ac repair <city>` | `heating and cooling <city> az`, `hvac contractor near <neighborhood>` |

Rules:
- Primary keyword appears in the page's `<title>`, `<h1>`, URL, and first paragraph — once,
  naturally. No stuffing.
- Don't create a page for a keyword the business can't serve.

## Check
- SEO audit: each page's title + H1 contain its primary keyword; no two pages share a primary.
