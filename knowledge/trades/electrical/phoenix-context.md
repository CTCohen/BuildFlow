# Electrical Phoenix-area context

## Rule
- Summer air conditioning load can strain older panels and circuits.
- Monsoon storms can cause outages and power surges.
- Many newer homes add EV chargers, which need capacity checks.
- Many older homes have panels or wiring that predate current loads.

These are general observations for copy, not verified facts. Each must be confirmed before it is used on a client site (`knowledge/pool/cities/phoenix.json` marks them unverified).

## Why
Local context makes copy specific to the area, which builds trust and helps local search.
