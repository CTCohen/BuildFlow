## Email Sending Workflow (Week 2)

### Monday Morning (9 AM PT)

**Batch 1: Send 5 emails**

1. Open Gmail / Outlook / your email client
2. For each of 5 prospects:
   - Create new email
   - Paste template
   - Fill in [Brackets]
   - Review for typos
   - Send
3. Log send time in spreadsheet (timestamp: 9:00 AM)

**Don't overthink.** Send within 30 min.

**Subject line examples (copy these):**
```
Mike, AZ HVAC Solutions is ranking higher than you on Google
Sarah, Rocky Mountain Plumbing is ranking higher than you on Google
David, Austin Electric Pro is ranking higher than you on Google
Lisa, Fresh Clean Services is ranking higher than you on Google
Tom, Apex Pressure Washing is ranking higher than you on Google
```

### Tuesday (24 hrs after send)

**Check email opens:**
- If using Gmail: Read receipts might not work (okay, skip this step)
- Assume 30-40% opened (that's industry average)
- No action yet (let them sit)

### Wednesday (48 hrs after send)

**Send SMS follow-up (for those who didn't open email)**
- Optional (email alone is fine)
- If sending SMS: Use template from `/messaging/SMS-HOOKS.md`
- Message: "Hi [Name]! Quick question: How many leads from your website last month? If under 5, we can help. Video: [LINK]. – BuildFlow"

### Thursday-Friday (72+ hrs after send)

**Monitor for replies:**
- Check email for responses
- Log any replies in spreadsheet
- Track calendar bookings
- Respond immediately to any questions

```

|------|----------|-------|------|--------|---------|---------|-------|-------------|-----------|---------|-------|-------|

| 9/16 | Sarah | sarah@... | 9:20a | | | | | | | | | No response |
| 9/16 | David | david@... | 9:25a | ? | ✓ | | | | | | | Clicked link |
```

**Track in real-time:**
- `Date` — When you sent
- `Prospect` — Name
- `Email` — Email address (for reference)
- `Sent` — Time sent
- `Opened` — Did they open? (✓ or ?)
- `Clicked` — Did they click portfolio link? (✓ or blank)
- `Replied` — Did they reply to email? (✓ or blank)
- `Reply` — What did they say?
- `Call Booked` — Did they book a call? (✓ or blank)
- `Call Date` — When is the call?
- `Closed?` — Did they buy? (✓ or blank)
- `Deal $` — Which plan? ($99/mo Managed Growth, or $497 Ownership)
- `Notes` — Anything else?

**This data shows:**
- Open rate % (replies / total sent)
- Click rate % (clicked / opens)
- Calendar booking rate % (booked / opens)
- Close rate % (closed / calls)

**After Batch 1 (5 emails):**
- If open rate <25%: Try different subject line for Batch 2
- If click rate <8%: Portfolio link isn't compelling, improve it
- If booking rate <15%: Calendar link issue or copy not strong

## FAQ: Email Sending

### Q: Should I personalize every email?
**A:** Yes. Takes 1 min per email. Makes huge difference.
- Generic emails: 15-20% open rate
- Personalized: 35-40% open rate
- That's 2x better = more closes

### Q: Can I use an email automation tool?
**A:** Yes, in Week 3+. For Batch 1 (5 emails), send manually.
- Manual = More authentic (shows personal attention)
- Automation = Scales to Batch 2 (5 more)
- If you want automation now: Zapier + Gmail or Mailchimp

### Q: What if they don't respond?
**A:** That's normal. Email response rate is 5-10%.
- Send Batch 1 (5 emails, 9 AM Mon)
- Wednesday: SMS follow-up (optional)
- Next week: Batch 2 to different 5 prospects
- Some will come back after a week

### Q: Should I wait for all responses before Batch 2?
**A:** No. Send Batch 1 Mon 9 AM. Send Batch 2 Fri 9 AM (same week).
- Batch 1: Mon (5 prospects)
- Batch 2: Fri (5 prospects)
- Both running in parallel

### Q: What's the expected result from 10 emails?
**A:** Conservative estimate:
- Open rate: 30% = 3 opens
- Click rate: 12% of opens = 1-2 clicks
- Calendar booking: 20% of opens = 0-1 calls
- Close rate: 35-50% = 0-1 closes

**Best case:**
- Open: 40% = 4 opens
- Click: 15% of opens = 1 click
- Book: 25% of opens = 1 call
- Close: 50% = 1 close

**Phase 1 approach:** Run Batch 1 (5 emails) + Batch 2 (5 emails) + learn + refine.
