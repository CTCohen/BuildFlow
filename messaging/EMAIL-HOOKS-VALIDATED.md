## Subject Lines (Ranked by Effectiveness)

### #1: Competitor Angle (Proven Best)
**Subject:**
```
[Name], [Competitor Name] is ranking higher than you on Google
```

**Metrics:** 35-40% open rate (vs. industry 25%)

**Why:**
- Specificity signals research done
- Competitor name = FOMO trigger
- "Ranking higher" = clear problem

**Email Body:**
```
Hi [Name],

I noticed [Competitor Name] is ranking above you on Google for "[Service]" in [City].

They're getting the calls you should be getting.

Quick question: How many leads came from your website last month?

Most contractors I talk to say "Not many." If that's you, we can fix it in 7 days.

See what we built: [PORTFOLIO_LINK]

5-min call? [CALENDAR_LINK]

[Your name]
BuildFlow
```

## Copy Patterns (Universally Effective)

### Pain Point Recognition
```
"Most contractors I talk to say [specific pain].
If that's you, we can fix it in [timeframe]."
```
- Acknowledges they have the problem
- Implies solution exists
- Reduces sales resistance

### Social Proof Formula
```
"We built sites for [# contractors] in [City/Industry].
Average result: [metric] new leads/month."
```
- Numbers are believable
- Local/industry relevance
- Concrete outcome

### ROI Reframe
```
"Managed website, live in 7 days, $99/mo.
Average ROI: 1 new job = $400-600 revenue.
One job every few months covers the year."
```
- Immediate payback
- Removes price objection
- Confidence signal

### Limited Availability
```
"Only [#] spots left for [timeframe]."
```
- Creates scarcity
- Drives decision urgency
- Use sparingly (only when true)

## Objection Handlers

### "I already have a website"
**Response:**
```
That's great! Quick question: How many new customers came from it last month?

If it's less than 5, most sites can be rebuilt and kept optimized for $99/mo.

Worth a quick call to see if it's worth doing? [CALENDAR]
```

### "Too expensive"
**Response:**
```
Totally get it. Here's how most clients think about it:

One job from a better website = $400-600 revenue.
Plan cost = $99/mo.
ROI: one extra job every few months covers a full year.

Everything after that is profit. Worth 5 minutes? [CALENDAR]
```

### "I can DIY it"
**Response:**
```
Definitely possible! Here's what most contractors find:

DIY: 20-40 hours of learning + building + fixing = ~$500-800 in time.
Risk: Design looks amateur, poor conversions, ongoing maintenance.

Done-for-you: 7 days, professional result, we host it and handle every update = $99/mo.

You decide what's worth your time. Happy to help either way.
```

### "I'm not interested"
**Response:**
```
No problem at all! One last thought though:

If you ever want to capture more leads online without monthly fees or learning design, keep us in mind.

Good luck with your business!
```

## Phone Call Script (Post-Click)

**Opening (30 sec):**
```
"Hi [Name]! Thanks for hopping on. We help contractors like you get more leads through a better website. 

Before we dive in, have you checked your Google ranking for [Service] + [City] lately?"
```

**Discovery (2 min):**
```
"Can I ask — last month, how many leads came directly from your website or Google?"

[Listen]

"Got it. That's pretty typical. Most contractors don't optimize for leads online.

We work with [trade type] contractors to turn their site into a lead-generating machine."
```

**Offer (1 min):**
```
"Here's what we do: We build a complete site, get you on Google Maps, set up call tracking. Live in 7 days.

Then we run it for you — hosting, security, ongoing SEO, any content changes. That's Managed Growth, $99/mo. No upfront cost, cancel anytime.

If a monthly plan isn't for you, we can do a one-time build you host yourself — $497, and then it's on you to maintain."
```

**Handle Objections (1 min):**
```
[If monthly concern]: "One extra job every few months covers the year. And you're paying for us to keep it working, not a file that rots."
[If already has site]: "We rebuild it and then keep improving it every month — that's the part yours is missing."
[If unsure]: "It's month-to-month, no lock-in. What questions do you have?"
```

**Close (30 sec):**
```
"Does this sound worth doing?"

[If yes]: "Great! I'll send you the signup link and info form. We start this week."
[If maybe]: "Let me send you 2 examples so you can see what we build."
[If no]: "No problem! Keep my info in case things change."
```
